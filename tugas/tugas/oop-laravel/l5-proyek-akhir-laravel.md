# L5 – Proyek Akhir Laravel

**Jenis:** Individu | **Tenggat:** Minggu 10 | **Bobot:** 25%

## Tujuan
Membangun aplikasi web profesional dengan Laravel yang menerapkan OOP, keamanan, dan praktik kerja tim industri.

## Instruksi
1. Ajukan proposal lewat **Issue** (judul: `Proposal L5 – Nama Kamu`). Disarankan berangkat dari **masalah nyata di tempat prakerin** (disamarkan) atau kebutuhan sekolah/komunitas.
2. Bangun aplikasi dengan minimal:
   - **Autentikasi** (starter kit resmi Laravel atau implementasi sendiri) dan **otorisasi** peran (admin/pengguna) memakai **Gate/Policy**.
   - **4 entitas** berelasi dengan CRUD, validasi, dan pencarian.
   - **Fitur lanjutan** (pilih minimal 3): upload berkas, ekspor PDF/Excel, grafik dashboard, notifikasi email (boleh log driver), antrean/queue, scheduler, REST API dengan **API Resource**, atau multi-bahasa.
   - **Arsitektur OOP rapi:** minimal satu penerapan dari *Service Layer*, *Repository (interface + implementasi)*, atau *Action class*, dengan **service container/binding** di Service Provider. Jelaskan alasan pilihan desainmu.
   - **Keamanan:** proteksi CSRF, validasi server, mass-assignment aman, tidak ada rahasia di repositori.
   - **Pengujian:** minimal 10 test (Feature dan Unit) yang lulus.
3. **Kerja Git profesional:** branch per fitur, minimal 20 commit bermakna, minimal 3 Pull Request yang digabung (*merge*) di repositorimu sendiri dengan deskripsi jelas.
4. **Deploy (nilai tambah):** hosting/VPS gratis atau video demo lengkap.

## Yang Dikumpulkan
- Tautan repositori proyek.
- `README.md` lengkap: latar belakang, fitur, teknologi, **diagram kelas dan ERD**, arsitektur, cara instalasi, akun uji, tangkapan layar, hasil pengujian, tautan demo.
- Presentasi 7–10 menit (demo + penjelasan desain OOP + tanya jawab).
- Satu paragraf refleksi: keputusan desain tersulit dan apa yang akan kamu ubah.

## Kriteria Keberhasilan
Aplikasi stabil, fitur lengkap, desain OOP bisa dijelaskan dan dipertahankan, keamanan dasar terpenuhi, pengujian lulus, riwayat Git profesional.
