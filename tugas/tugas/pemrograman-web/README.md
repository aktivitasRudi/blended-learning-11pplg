| No | Tugas | Fokus | Tenggat | Bobot |

| W1 | [Landing Page Responsif](w1-landing-page-responsif.md) | HTML5 semantik, CSS, Flexbox/Grid | Minggu 2 | 20% |
| W2 | [JavaScript Interaktif & API](w2-javascript-interaktif.md) | DOM, validasi form, fetch API | Minggu 4 | 25% |
| W3 | [PHP Native + MySQL (CRUD)](w3-php-mysql-crud.md) | PHP, PDO, prepared statement | Minggu 6 | 25% |

## Aturan umum
- Setiap tugas berisi `README.md` sendiri: deskripsi, cara menjalankan, tangkapan layar.
- Dilarang menaruh password database asli dan API key di repositori. Gunakan `config.example.php` dan `.gitignore`.
- Minimal 5 commit bermakna per tugas.
- Boleh memakai AI atau tutorial sebagai bantuan belajar, tetapi kamu harus bisa menjelaskan setiap baris kodemu saat ditanya guru. Cantumkan sumber/bantuan yang dipakai di README.
