# W2 – JavaScript Interaktif & API

**Jenis:** Individu | **Tenggat:** Minggu 4 | **Bobot:** 25%

## Tujuan
Menambahkan interaktivitas dengan JavaScript, memanipulasi DOM, memvalidasi input, dan mengambil data dari API.

## Pilih SATU aplikasi
1. **Daftar tugas (To-Do) lengkap** dengan kategori dan filter.
2. **Kalkulator/konverter** yang berguna (misalnya konversi mata uang, kalkulator biaya proyek).
3. **Dashboard cuaca/berita/kurs** dari API publik.
4. **Kuis interaktif** bertema pemrograman.

## Persyaratan Teknis
1. JavaScript modern (ES6+): `const/let`, arrow function, template literal, destructuring, `async/await`.
2. **Manipulasi DOM:** buat, ubah, dan hapus elemen secara dinamis. Hindari `innerHTML` dengan input pengguna mentah (risiko XSS). Jelaskan cara kamu mengatasinya.
3. **Validasi form** sisi klien (kolom wajib, format email, panjang minimal) dengan pesan error yang jelas.
4. **Fetch API:** minimal satu panggilan ke API publik, dengan penanganan *loading*, *error*, dan *data kosong*.
5. **Penyimpanan lokal:** gunakan `localStorage` agar data tidak hilang saat halaman dimuat ulang.
6. Kode dipecah ke beberapa fungsi bernama jelas, minimal 5 fungsi, dan file JS terpisah.
7. Tidak ada `console.log` sisa debugging di versi akhir.

## Yang Dikumpulkan
- Folder `w2-js-interaktif/`.
- `README.md`: fitur, API yang dipakai (tautan dokumentasi), cara menjalankan, tangkapan layar atau GIF demo.
- Bagian **"Yang Saya Pelajari"** (5–8 kalimat) tentang kesulitan terbesarmu dan solusinya.

## Kriteria Keberhasilan
Semua fitur berfungsi, error ditangani, kode terstruktur, tidak ada kerentanan XSS yang jelas.
