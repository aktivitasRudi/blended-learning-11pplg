# W4 – Proyek Web Mini

**Jenis:** Individu | **Tenggat:** Minggu 8 | **Bobot:** 30%

## Tujuan
Mengintegrasikan front-end dan back-end dalam satu aplikasi web utuh yang siap dipamerkan sebagai portofolio.

## Instruksi
1. Ajukan proposal lewat **Issue** (judul: `Proposal W4 – Nama Kamu`): masalah, pengguna, fitur utama, dan teknologi.
2. Bangun aplikasi web dengan minimal:
   - **3 halaman utama** + halaman login.
   - **2 peran pengguna** (misalnya admin dan pengguna biasa) dengan hak akses berbeda.
   - **CRUD** minimal untuk 2 entitas berelasi.
   - **Fitur tambahan** (pilih minimal 2): upload gambar/berkas, cetak/ekspor laporan (PDF/CSV), grafik statistik, pencarian dan filter lanjutan, notifikasi, REST API sederhana (JSON).
   - Tampilan **responsif** dan UX yang konsisten.
3. **Pengujian:** tabel minimal 8 skenario uji (skenario, langkah, hasil diharapkan, hasil aktual, status).
4. **Deploy (nilai tambah):** hosting gratis (misalnya InfinityFree, atau lainnya) atau demo lokal berupa video.

## Yang Dikumpulkan
- Folder `w4-proyek-mini/` dengan `database.sql`.
- `README.md` lengkap: latar belakang, fitur, teknologi, ERD, cara instalasi, akun uji, tangkapan layar, tabel pengujian, dan tautan demo.
- Riwayat commit minimal 15 commit bermakna.
- Presentasi 5–7 menit (bila diminta guru).

## Kriteria Keberhasilan
Aplikasi stabil dan lengkap fiturnya, aman dasar, tampilan baik, dokumentasi dan pengujian jelas.
