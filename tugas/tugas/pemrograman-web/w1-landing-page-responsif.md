# W1 – Landing Page Responsif

**Jenis:** Individu | **Tenggat:** Minggu 2 | **Bobot:** 20%

## Tujuan
Membuat halaman web statis yang rapi, semantik, dan tampil baik di ponsel maupun desktop.

## Skenario
Buat landing page untuk **salah satu**:
- (a) Profil perusahaan tempat prakerinmu (data umum saja, tanpa data rahasia), atau
- (b) Portofolio pribadimu sebagai siswa PPLG, atau
- (c) Produk/jasa fiktif sesuai idemu.

## Persyaratan Teknis
1. **HTML5 semantik:** `header`, `nav`, `main`, `section`, `article`, `footer`; satu `h1`; atribut `alt` pada gambar; `lang` dan `meta viewport`.
2. Minimal **5 bagian:** Hero, Tentang, Layanan/Fitur (min. 3 kartu), Galeri atau Testimoni, Kontak (form).
3. **CSS terpisah** (`style.css`), tanpa CSS inline berlebihan. Gunakan CSS variable untuk warna dan font.
4. **Layout** memakai Flexbox dan/atau Grid. Tidak memakai `<table>` untuk tata letak.
5. **Responsif:** minimal 2 breakpoint (mobile, tablet/desktop) memakai media query. Menu navigasi berubah di layar kecil.
6. Menu navigasi dengan *anchor link* ke tiap bagian dan *smooth scroll*.
7. Skor **Lighthouse** (Chrome DevTools) minimal 80 untuk Performance dan Accessibility. Tangkapan layar hasilnya masuk README.
8. Boleh memakai framework CSS (Bootstrap/Tailwind) **hanya jika** kamu juga menulis minimal 50 baris CSS sendiri dan menjelaskan alasan pemilihannya di README.

## Yang Dikumpulkan
- Folder `w1-landing-page/` (index.html, style.css, assets).
- `README.md`: deskripsi, tautan **GitHub Pages** (aktifkan di Settings → Pages), tangkapan layar tampilan desktop dan mobile, skor Lighthouse.

## Kriteria Keberhasilan
Struktur HTML benar, tampilan konsisten dan responsif, dapat diakses online lewat GitHub Pages, kode rapi dan ter-indentasi.
