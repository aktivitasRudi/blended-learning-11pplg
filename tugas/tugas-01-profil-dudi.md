# Tugas 1 – Profil DUDI & Setup Repositori

**Jenis:** Individu | **Tenggat:** Minggu 1 | **Bobot:** 10%

## Tujuan
Mengenal tempat prakerin dan menyiapkan repositori pribadi sebagai pusat dokumentasi.

## Instruksi
1. Fork repositori ini dan buat folder `submissions/NN-nama-kamu/`.
2. Buat file `profil-dudi.md` berisi:
   - **Identitas perusahaan:** nama, alamat, bidang usaha, jumlah karyawan (perkiraan), situs web.
   - **Struktur tim IT:** divisi atau tim tempatmu ditempatkan, nama dan jabatan pembimbing lapangan.
   - **Bidang pekerjaan:** produk/layanan yang dibuat atau dikelola, dan siapa penggunanya.
   - **Lingkungan kerja:** perangkat, sistem operasi, tools komunikasi (Slack, WhatsApp, Jira, dll.), jam kerja.
   - **Budaya dan aturan kerja:** K3, kedisiplinan, etika berkomunikasi.
   - **Target pribadi:** 3 hal yang ingin kamu kuasai selama prakerin dan alasannya.
3. Lengkapi `README.md` di folder pribadimu: foto/avatar (opsional), nama, kelas, tempat prakerin, dan daftar tugas.
4. Kumpulkan lewat Pull Request.

## Ketentuan
- Panjang minimal 300 kata, format Markdown rapi (judul, daftar, tabel bila perlu).
- Jangan mencantumkan data pribadi sensitif (nomor HP pribadi, alamat rumah).

## Kriteria Keberhasilan
Profil lengkap, akurat, ditulis dengan bahasa sendiri, dan PR terkirim sesuai alur Git.
