# Tugas 4 – Mini Project / Kontribusi Nyata

**Jenis:** Individu | **Tenggat:** Minggu 6 | **Bobot:** 30%

## Tujuan
Menerapkan kompetensi PPLG dalam bentuk karya nyata yang bisa dipamerkan sebagai portofolio.

## Pilih SATU jalur

**Jalur A – Proyek dari DUDI.** Dokumentasikan kontribusimu pada satu fitur atau tugas nyata di tempat prakerin (setelah mendapat izin). Sertakan versi disamarkan/tanpa data rahasia.

**Jalur B – Proyek mandiri terinspirasi DUDI.** Bangun aplikasi kecil yang menyelesaikan masalah yang kamu temui di tempat prakerin. Contoh: aplikasi pencatat inventaris, dashboard laporan sederhana, bot pengingat, API kecil, game edukasi, atau tools otomasi.

## Instruksi
1. Ajukan ide lewat **Issue** di repositori ini (judul: `Proposal Mini Project – Nama Kamu`) berisi masalah, solusi, dan teknologi. Tunggu persetujuan guru.
2. Buat folder `projects/nama-proyek/` di folder pribadimu (atau repositori terpisah, lalu tautkan di README).
3. Wajib ada:
   - **Kode sumber** yang rapi dan bisa dijalankan.
   - **README.md** proyek: deskripsi, fitur, teknologi, cara instalasi, cara menjalankan, dan tangkapan layar.
   - **Riwayat commit** minimal 10 commit bermakna (bukan satu commit besar).
   - **Dokumentasi pengujian:** minimal 5 skenario uji (tabel: skenario, hasil diharapkan, hasil aktual).
4. Sertakan **video demo singkat** (1–3 menit, tautan YouTube *unlisted* atau Drive) atau GIF.
5. Kumpulkan lewat Pull Request dan siapkan presentasi singkat (5 menit) bila diminta guru.

## Ketentuan
- Bahasa dan stack bebas selama sesuai kompetensi PPLG.
- Jangan menaruh API key atau password di repositori. Gunakan `.env` dan `.gitignore`.
- Lisensi dan referensi library harus dicantumkan.

## Kriteria Keberhasilan
Proyek berjalan, kode terstruktur, dokumentasi jelas, riwayat commit sehat, dan ada pengujian.
