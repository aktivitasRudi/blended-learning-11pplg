# Rubrik Penilaian

Skala tiap aspek: **4** (Sangat Baik), **3** (Baik), **2** (Cukup), **1** (Kurang).

## Rubrik umum (semua tugas)
| Aspek | 4 | 3 | 2 | 1 |
|-------|---|---|---|---|
| Kelengkapan | Semua bagian lengkap dan melampaui ketentuan | Semua bagian lengkap | Sebagian bagian kurang | Banyak bagian hilang |
| Kualitas isi | Spesifik, akurat, mendalam | Akurat, cukup rinci | Umum/dangkal | Tidak relevan atau keliru |
| Ketepatan waktu | Sebelum tenggat | Tepat tenggat | Terlambat ≤ 3 hari | Terlambat > 3 hari |
| Kerapian Git | PR rapi, commit bermakna, struktur benar | PR benar, commit cukup jelas | Struktur/commit kurang rapi | Tidak mengikuti alur Git |
| Profesionalisme | Bahasa baik, tanpa data rahasia, orisinal | Sedikit catatan | Beberapa pelanggaran kecil | Ada data rahasia/plagiarisme |

**Nilai = (total skor ÷ 20) × 100**
